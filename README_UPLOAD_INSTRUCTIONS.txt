Ahmed Mahmoud Portfolio + InfraDispatch V10

UPLOAD TO BLUEHOST
1. Unzip this package.
2. Upload the CONTENTS of this folder to public_html.
3. index.html must be directly inside public_html.
4. Keep the folders assets, data, downloads, infradispatch, experience and about.

IMPORTANT
- InfraDispatch is a static live beta planner.
- Route links use Google Maps only in this version.
- Print / Save as PDF opens a dedicated print-ready manifest window.
- Workspace/local profile is optional and stored only in the browser.
- Custom places are stored only in the browser.
- This delivery is a static website package for public_html. No backend starter files are included.

FILES
- /infradispatch/ is the main product planner.
- /data/locations.json contains the static beta location database.
