# Upload Checklist - Ahmed Mahmoud Operations Atlas Portfolio

## Recommended Design Direction
- Use this **Operations Atlas** version as the best current form.
- It is stronger than the earlier color concept because it feels premium, focused, and recruiter-safe.
- Keep **InfraDispatch** as the flagship project and keep the static/demo boundary visible.

## Before Upload
- Open `index.html` locally and check the full page from top to bottom.
- Confirm the portrait image loads.
- Confirm all project and insight visuals load.
- Test the navigation links: Work, Case, Insights, Palette, Top.
- Check mobile view or narrow browser width.
- Confirm there is no missing-image icon.
- Confirm text does not overlap on mobile.
- Confirm spelling for visible headings and project descriptions.

## Hosting Upload
- Upload the full contents of this folder, not only `index.html`.
- Keep the `assets` folder beside `index.html`.
- The final structure should look like:
  - `index.html`
  - `assets/ahmed-mahmoud-photo-executive.jpeg`
  - `assets/articles/...`
  - `assets/og/...`
  - `assets/og-v14/...`
  - `assets/insights/...`

## Demo / Static Boundaries
- This is a static visual website.
- InfraDispatch is presented as a smart rule-based dispatch planner/demo.
- No backend, login, live routing, traffic, inventory, OTA, account system, or API is included.
- Do not describe it as a live production platform until those systems exist.

## Final Clean-Up After Upload
- Check the live URL in desktop and mobile.
- Check browser console for missing assets or errors.
- Submit the live URL to Google Search Console if this replaces the current site.
- Add analytics only if the tracking script is ready and safe to expose publicly.
- Update `sitemap.xml` and `robots.txt` only if this package becomes the main website.

## Remaining Improvements
- Add a contact section or email link before public launch.
- Replace concept copy with final recruiter-focused copy.
- Connect project cards to real project pages when those pages are ready.
- Add SEO Open Graph image and favicon if this becomes the production homepage.
