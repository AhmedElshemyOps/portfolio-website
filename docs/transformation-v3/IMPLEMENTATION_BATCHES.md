# F. Future implementation batches

The batches are planning labels for related changes. Execute sub-slices strictly in V3.0 phase order. A work package spanning phases waits for its later phase. Gate 2 approves design/taxonomy/architecture, Gate 3 approves implementation readiness, publishing architecture and project-refactor scope, and Gate 4 approves final acceptance and production deployment. Obtain any separate approval listed in V3.0 Section V. This document authorizes no batch.
