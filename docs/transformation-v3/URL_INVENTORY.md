# URL inventory

See [tracked HTML and canonical inventory](url-inventory.tsv), [sitemap URLs](sitemap-urls.txt) and [public verification evidence](public-verification.tsv). The HTML inventory records file paths, corresponding URL candidates, index hints, canonical URLs and Git blob IDs. Directory aliases are listed separately in the TSV. A tracked path or an inferred directory alias alone does not imply inclusion in the public index. The verification file identifies responses actually requested. Preserve all existing public paths and anchors.
