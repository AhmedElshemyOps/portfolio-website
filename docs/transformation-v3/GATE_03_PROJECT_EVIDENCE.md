# Four-project protected regression evidence

Chrome ran the four demos from a local archive of protected master `753c3a0cc6e2235201e939b840973911725dc00c`. The temporary browser harness filled existing form controls, invoked existing buttons, checked rendered results and intercepted generated export blobs for inspection. It used synthetic or built-in demo data. No published project or input was changed.

| Project | Fixture | Expected and observed |
| --- | --- | --- |
| [InfraQuote](https://github.com/AhmedElshemyOps/portfolio-website/blob/753c3a0cc6e2235201e939b840973911725dc00c/live-demos/infraquote.html) | Abu Dhabi, full day, four adults and one child, QA Sample Company, default costs | Positive AED quote and exact agreement between the calculator and JSON, worksheet header and currency, matching saved inputs and step advance. Passed. Quote was AED 4,000.50. The initial run without required duration correctly blocked advancement. |
| [InfraDispatch](https://github.com/AhmedElshemyOps/portfolio-website/blob/753c3a0cc6e2235201e939b840973911725dc00c/live-demos/infradispatch/index.html) | Built-in Abu Dhabi City Tour fixture, QA Dispatcher | Three pickups, seven passengers and one child seat, results disclosure opens, JSON matches the fixture and HTML names the tour, local operator name is saved. Passed. The timeline estimated 65 minutes and the database marker was 2026-07-02. |
| [InfraSky](https://github.com/AhmedElshemyOps/portfolio-website/blob/753c3a0cc6e2235201e939b840973911725dc00c/live-demos/infrasky.html) | Default Al Ain / Jebel Hafeet Foothills, 16 passengers, 15 June 2030 | Decision and score in range, saved date and passenger count, matching JSON with an InfraDispatch handover and result-tab selection. Passed. Estimated result was SELL, 80/100. |
| [InfraCluster](https://github.com/AhmedElshemyOps/portfolio-website/blob/753c3a0cc6e2235201e939b840973911725dc00c/live-demos/infracluster.html) | Built-in demo groups | Six groups, 56 passengers, nonzero clusters, six data rows in CSV, 56 passengers in InfraDispatch JSON and wizard advance. Passed. Observed four clusters and AED 3,569 estimated cost. |

The scenario flows ran at 1,250 px. At 390 px all four had visible main content and no root horizontal overflow. The reported document/main width was 375 px in each 390 px iframe. Browser screenshots in the verification session show the desktop summary and narrow project views. The screenshot images are available in the session output. This branch records the results in text.

Persistence evidence covers browser storage immediately after saving. Export evidence covers generated payloads. Disk downloads, browser PDF printing, reload and cross-session restore, spreadsheet import, live weather/maps, cloud integrations, and full mobile interaction and accessibility coverage remain outside the observed scenarios. The health run also passed the separate InfraQuote calculation, workspace, Amsterdam, PDF and backend test files. Before comparing a future candidate, repeat the four fixtures at the same widths and compare relevant project runtime and asset hashes against pinned master.
