# UX Notes

## UX Goals
1. Visitor understands Ahmed in <5 seconds.
2. Visitor understands InfraDispatch in <15 seconds.
3. Visitor can run simulator in <1 minute.
4. Recruiter can evaluate operations + product thinking quickly.

## UX Decisions
- Hero with trust badges and clear CTA pair.
- Problem/Solution narrative before deep product details.
- Simulator with map + output + action buttons.
- Case study page for strategic depth.
- Clear demo/static labeling to avoid false live-ops claims.

## Accessibility Baseline
- Maintain strong contrast in navy/gold palette.
- Use semantic headings and structured section labels.
- Keep button labels explicit and action-oriented.
