# Deployment Notes

## Static Hosting (Bluehost/cPanel)
1. Upload project files to `public_html`.
2. Keep folder structure unchanged (`assets/`, `downloads/`, `infradispatch/`, `about/`).
3. Verify `index.html` is at root.

## GitHub Pages
1. Push repo to GitHub.
2. Enable Pages from `main` branch root.
3. Use published URL for portfolio linking.

## Vercel
1. Import repository.
2. Use static deployment (no build command required).
3. Deploy root folder.
