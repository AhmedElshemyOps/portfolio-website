# InfraDispatch Product Roadmap

## Current Demo Scope (Static/Prototype)
- Scenario builder with sample datasets
- Route preview map panel (Leaflet/OSM)
- Dispatch results, ETA, risk indication
- WhatsApp brief generation
- Pickup sheet export
- Dashboard status preview

## Phase 2 (Operational MVP)
- Backend data storage
- User accounts and role access
- Driver/guide/vehicle master data
- Dispatch history and activity logs
- PDF manifest generation service

## Phase 3 (Routing Intelligence)
- OSRM-based routing service
- Optional Google/HERE/TomTom routing adapters
- Traffic-aware ETA matrices
- Multi-map navigation links and policy routing

## Phase 4 (Enterprise Ops)
- SLA monitoring and delay root-cause analytics
- Supplier reliability scoring
- Hero replacement recommendation engine
- Settlement and operational reporting modules
