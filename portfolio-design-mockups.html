04 / Design System Notes

Implementation guide

These tokens and layout rules keep the mockups consistent when translated into the current static website.

Responsive behavior

Desktop uses multi-column evidence layouts. Tablet collapses to two-column grids. Mobile becomes a single editorial column with shorter image slots and clear section anchors.

Color Scheme

Navy for authority, gold for expertise signals, white cards for clarity, cool gray for operational calm.

Typography

Serif display headings for executive editorial authority. Arial/sans UI text for labels, cards, chips, and metadata.

Spacing & Components

8px radius, 16px card gaps, 72px section rhythm, dashed placeholders for assets, concise metadata chips.

Desktop3-column portfolio grid, 2-column case study, 3-card insights feed.
TabletPortfolio and insights reduce to two columns; case sidebar stacks below detail.
MobileAll sections become one column; image slots stay labeled and content remains scannable.
Mockup boundary: This is a static visual framework and content-planning artifact. It uses placeholder text and mock image slots; it does not add live backend, API integrations, analytics events, or real project data wiring.
