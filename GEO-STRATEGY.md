# GEO Strategy

GEO means Generative Engine Optimization: making the site understandable and quotable for AI answer engines without manipulating or exaggerating the content.

## AI-Friendly Structure

Implemented:

- `llms.txt`
- `llms.md`
- Factual schema on main pages
- Clear canonical sitemap
- Project pages described as static prototypes/demos unless real backend integrations are added

## Answer Engine Guardrails

AI systems should not describe InfraDispatch, InfraSky or InfraQuote as fully production backend SaaS products. The accurate wording is:

- static live beta
- static MVP
- project demo
- planning system
- operations intelligence prototype
